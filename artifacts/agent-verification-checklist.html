The Agent Verification Checklist

Ten questions I run against any AI agent's claim of "done" before I believe it. Check them off as you go. Your progress stays in this browser and nowhere else.

Every one of these comes back to the same failure. An agent, or a person, or a vendor says a thing is finished, and the only evidence is the sentence itself. That isn't verification. It's a claim wearing verification's clothes. So the test I apply to every item on this list, including the list itself, is simple. Can I name the exact thing that would prove it false? If I can't, it doesn't belong here.

Where this comes from

I run a home server and a set of automated workflows for my own projects. Trading tools, side builds, small sites like this one. The failure mode I keep guarding against isn't the agent doing the wrong thing. It's the agent, or the report, or the pull request, or the contractor, confidently telling me it did the right thing with nothing behind the sentence. This list is what I actually check before I believe "done." It's short on purpose, because a checklist you won't run isn't a checklist. It's a wish.
